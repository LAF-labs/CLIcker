# CLIcker

CLIcker is a PTY-based clickable control surface for terminal AI coding agents.

It wraps tools such as Claude Code, Codex CLI, Gemini CLI, Cursor CLI, GitHub Copilot CLI, OpenCode, Aider, Cline, Devin, Hermes, Goose, and Qwen Code without replacing them.

```bash
npm install
npm run dev -- claude
npm run dev -- adapters
```

The product name is **CLIcker**. The local binary is `clicker`.

See [docs/SPEC.md](docs/SPEC.md) for the v1.1 product and technical specification.
